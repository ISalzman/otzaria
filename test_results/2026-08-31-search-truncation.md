# issue #1053 — חיפוש בספר: חיווי כשהתוצאות נחתכות בתקרת ה-1000

תאריך: 2026-08-31 | ענף: `feature/search-truncation-notice-1053` | קומיט קוד: `c46cf002`

## הבאג

החיפוש בתוך ספר עוצר בתקרת 1000 תוצאות באמצע הספר ומציג "נמצאו 1000
תוצאות" — בלי שום סימן שהסריקה לא כיסתה את השאר. אחרי #1046 (התאמה חלקית
כברירת מחדל) חציית הסף היא שגרה בכל שאילתה קצרה. אומת בגרסה 0.9.95:
"רבי" ו"אמר" בברכות — שניהם "נמצאו 1000 תוצאות" בלי חיווי
(`img/1053-before-rabi.jpg`, `img/1053-before-amar.jpg`).

## הפתרון

- ה-worker (`section_search_utils.dart`) מחזיר דגל `truncated` לצד התוצאות:
  מדויק גם במקרי הקצה — בדיוק-1000 הופעות בלי שארית אינו מסומן כחתוך;
  הופעות עודפות בשורת-הסף כן.
- `searchInContent` חושף את הדגל דרך `onTruncated` — בלי לשבור את חתימת
  ההחזרה של עשרות אתרי-קריאה קיימים.
- הכיתוב בסרגל התוצאות (`text_book_search_screen.dart`) הופך ל"מוצגות
  N התוצאות הראשונות" — **בשני המסלולים**: המקומי (worker) וגם מסלול
  המנוע, שחותך אף הוא ב-1000 (`displayLimit`) באותו סימפטום.
