# קבצי תשתית לתוספים

קבצים אלו מיועדים למפתחי תוספים לאוצריא — **לא לשימוש פנימי של האפליקציה**.

## קבצי ה-SDK

| קובץ | תוכן |
|------|------|
| `otzaria_plugin.js` | ספריית ה-JS שכל תוסף מייבא ב-`index.html` שלו |
| `otzaria_plugin.d.ts` | הגדרות TypeScript — מאפשרות השלמה אוטומטית ב-IDE |

## תוסף דמו

תיקיית `example/` מכילה תוסף דמו מוכן — לוח שנה עברי — המדגים קריאת נתוני לוח שנה, חיפוש בטקסט ופרסום אירועים חזרה לאוצריא.

| קובץ | תוכן |
|------|------|
| `example/manifest.json` | manifest של תוסף הדמו |
| `example/index.html` | קוד ה-HTML/JS המלא של תוסף הדמו |

מדריך פיתוח מלא נמצא ב-`docs/plugin-sdk/`.
