# הגנה על איפוס הגדרות במצב מוגן

## סקירה כללית

החל מעדכון זה, פעולת "איפוס הגדרות" בהגדרות המתקדמות מוגנת בסיסמה כאשר המצב המוגן מופעל.

## מטרת השינוי

למנוע איפוס מקרי או לא מורשה של כל הגדרות האפליקציה כאשר המצב המוגן פעיל. זה מוסיף שכבת אבטחה נוספת לפעולה קריטית שמוחקת את כל ההגדרות האישיות.

## שיפורים נוספים

### טיפול בביטול כניסה להגדרות
כאשר משתמש מנסה להיכנס להגדרות במצב מוגן ולוחץ על "ביטול" בדיאלוג הסיסמה:
- האפליקציה לא קורסת (תוקן!)
- המשתמש חוזר למסך הקודם בצורה חלקה
- אם המשתמש נשאר במסך ההגדרות, מוצגת הודעה ברורה: "הנך במצב מוגן - אין אפשרות להיכנס להגדרות ללא סיסמה"

## איך זה עובד?

### כניסה להגדרות במצב מוגן
1. כאשר משתמש מנסה להיכנס להגדרות
2. המערכת בודקת אם המצב המוגן מופעל
3. אם כן, מוצג דיאלוג לאימות סיסמה
4. אם המשתמש מזין סיסמה נכונה - נכנס להגדרות
5. אם המשתמש לוחץ על "ביטול" - חוזר למסך הקודם או רואה הודעה מתאימה

### איפוס הגדרות במצב מוגן
1. כאשר משתמש לוחץ על "איפוס הגדרות" בהגדרות המתקדמות
2. המערכת בודקת אם המצב המוגן מופעל
3. אם כן, מוצג דיאלוג לאימות סיסמה
4. רק לאחר הזנת סיסמה נכונה, מוצג דיאלוג האישור הרגיל
5. לאחר אישור, ההגדרות מאופסות

## קוד לדוגמה

### הגנה על איפוס הגדרות
```dart
// בדיקה אם במצב מוגן - אם כן, דרוש אימות סיסמה
if (context.mounted && shouldProtectSettings(context)) {
  final verified = await verifyPasswordForAction(context);
  if (!verified || !context.mounted) {
    return; // המשתמש ביטל או הסיסמה שגויה
  }
}

if (!context.mounted) return;

// המשך לדיאלוג האישור הרגיל...
```

### טיפול בביטול כניסה להגדרות
```dart
if (verified == true) {
  setState(() {
    _isVerified = true;
  });
} else {
  // המשתמש ביטל - נחזור למסך הקודם בצורה בטוחה
  WidgetsBinding.instance.addPostFrameCallback((_) {
    if (mounted) {
      Navigator.of(context).pop();
    }
  });
}
```

## פונקציות עזר

השינוי משתמש בפונקציות קיימות מ-`protected_settings_wrapper.dart`:

- `shouldProtectSettings(BuildContext context)` - בודק אם צריך הגנה
- `verifyPasswordForAction(BuildContext context)` - מציג דיאלוג אימות סיסמה

## התנהגות

### כאשר המצב המוגן מופעל:

#### כניסה להגדרות:
1. ניסיון כניסה להגדרות → דיאלוג סיסמה
2. הזנת סיסמה נכונה → כניסה להגדרות
3. לחיצה על "ביטול" → חזרה למסך הקודם או הצגת הודעה

#### איפוס הגדרות:
1. לחיצה על "איפוס הגדרות" → דיאלוג סיסמה
2. הזנת סיסמה נכונה → דיאלוג אישור
3. אישור → איפוס ההגדרות

### כאשר המצב המוגן כבוי:
1. כניסה להגדרות → כניסה ישירה
2. לחיצה על "איפוס הגדרות" → דיאלוג אישור ישירות
3. אישור → איפוס ההגדרות
